Premium Feature — Hata Defteri

SM-2 Algoritmasıyla Akıllı Tekrar

Yanlış yapılan soruları veya anlaşılmayan konuları sisteme kaydet. SM-2 aralıklı tekrar algoritması, her sorunun ne zaman tekrar gösterileceğini optimize eder.

🧠

Bilgi Kalıcılığı (Spaced Repetition)

Soruyu ne kadar kolay hatırladığını puanla (0-3). Sistem bir sonraki tekrarını gün bazında ayarlar.

📅

Sade Tekrar Listesi

"Bugün tekrar edilecek" sekmesi — sadece senin o gün görmen gereken kritik soruları gösterir, beyni yormaz.

🔬 SM-2 Arka Planı

Kolay hatırlanan soruyu 7 gün sonra, zor olanı 1 gün sonra gösterir. Zamanla tekrar aralıkları uzar, bilgiyi "kısa süreli" bellekten "uzun süreli" belleğe zorlar.

Technical Architecture

Modern ve Işık Hızında Altyapı

Performanstan ödün vermeyen bulut tabanlı bir mimari. Animasyonlar React üzerinde sorunsuz 60 FPS çalışır.

React 19 + Vite

Hot module replacement, ekstrem paket yükleme hızları, client-side routing.

Firebase Data Sync

Çevrimdışı destekli Firestore. Verin saniyesinde buluta işlenir.

Google Gemini LLM

Büyük dil modellerinin API üzerinden konuşlandırılması, düşük gecikmeli AI.

21st MCP & UI Kütüphaneleri

Framer Motion, Glassmorphism, TailwindCSS destekli premium UX yaklaşımı.

🔐 Güvenlik Standardı

Oturum yönetimi kriptolanmıştır. Güvenlik kuralları veritabanı (Firestore Rules) aşamasında denetlenir.

📱 Mobil Uyumlu / PWA

Sistemin tamamı cep telefonu ekranına sığar. Tarayıcıdan Ana Ekran'a eklenerek native bir uygulama gibi kullanılabilir.

☁️ Zero-Downtime Deploy

Vercel Edge ağı üzerinden CI/CD pipeline'ı ile kesintisiz güncelleme sunulur.
